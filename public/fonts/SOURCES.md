# Local fonts

DM Sans and Space Grotesk regular/semibold downloaded from the official Google Fonts CSS API and its fonts.gstatic.com CDN on 2026-10-16. Corresponding SIL Open Font License files are preserved from https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/spacegrotesk. Fonts are served locally; the application does not call Google Fonts at runtime.
